# La memoria procedimental como agregado de destrezas

## Definición

Frente a la concepción de la [[memoria-no-declarativa|memoria procedimental]] como un sistema unitario opuesto en bloque a la [[memoria-declarativa]], esta síntesis recoge la tesis de que la memoria procedimental es **un agregado de muchas destrezas heterogéneas**, no necesariamente dependientes de un único sistema neuroanatómico [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.13](https://doi.org/10.1080/01688639008400978#page=13). La formulación se atribuye a [[larry-squire|Squire (1987)]], y constituye una alternativa al [[modelo-declarativo-procedimental]] de doble disociación neta.

## Evidencia de disociación intra-procedimental

La principal evidencia conductual proviene de mostrar que dos tareas clásicamente procedimentales —[[tarea-de-rotary-pursuit|rotary pursuit]] (motora) y [[tarea-de-mirror-reading|mirror reading]] (visuoperceptiva)— pueden **disociarse** en pacientes con Parkinson: el déficit aparece en una y no en la otra, y la cantidad de aprendizaje no correlaciona entre tareas [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.13](https://doi.org/10.1080/01688639008400978#page=13). Esto fue presentado como el primer estudio en reportar diferencias de rendimiento **entre** tareas procedimentales en el PD, indicando que deben diferir en uno o más procesos componentes [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.13](https://doi.org/10.1080/01688639008400978#page=13). La cuenta procedimentalista de Kolers y Roediger ya sugería que algunos procesos son específicos de la tarea, contrastando con la visión procedimental-declarativa [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.5](https://doi.org/10.1080/01688639008400978#page=5).

## Implicaciones para el sustrato neural y la teleosemántica

Si cada destreza procedimental recluta procesos componentes distintos, el neostriado no puede considerarse el regulador de toda destreza procedimental: los [[estriado|ganglios basales]] subservirían el aprendizaje motor pero no el visuoperceptivo [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.15](https://doi.org/10.1080/01688639008400978#page=15). Una consecuencia más radical es que el sistema diencefálico-temporal medial podría no ser el sustrato de la memoria declarativa *per se*, sino regular ciertos procesos componentes [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.13](https://doi.org/10.1080/01688639008400978#page=13), y que el conocimiento procedimental puede ser tan específico que ni siquiera se separe limpiamente del declarativo, requiriendo el aprendizaje la interacción de ambos en grados variables [Procedural memory in Parkinson's disease: Impaired motor but not visuoperceptual learning, p.14](https://doi.org/10.1080/01688639008400978#page=14). Para un enfoque teleosemántico, esto reorienta la individuación de los sistemas de memoria desde categorías fenoménicas hacia los **procesos funcionales** que cada tarea moviliza, en línea con la [[individuacion-funcional-de-los-sistemas-de-memoria|individuación funcional]] de los sistemas de memoria.
