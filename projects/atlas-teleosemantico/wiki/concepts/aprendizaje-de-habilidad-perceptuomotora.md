# Aprendizaje de habilidad perceptuomotora

## Definición

El **aprendizaje de habilidad perceptuomotora** es una forma de [[memoria-no-declarativa]] que ocurre sin conciencia del contenido aprendido, estudiada con la tarea de tiempo de reacción serial [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). En ella, amnésicos y controles muestran un aprendizaje equivalente de una secuencia repetida de 10 localizaciones a lo largo de 400 ensayos, con tiempos de reacción que mejoran progresivamente y vuelven a empeorar cuando se introduce una secuencia aleatoria [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2).

## Independencia del conocimiento consciente

Cuatro tests de conocimiento declarativo indicaron que los amnésicos eran inconscientes de lo que habían aprendido [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). El conocimiento declarativo que adquieren los controles no es necesario para aprender la secuencia ni contribuye a los tiempos rápidos: se adquiere de forma concomitante, como un subproducto y no como la base del desempeño [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). El caso ilustra cómo una misma experiencia puede dejar huellas en sistemas distintos, separables por sus características operativas (véase [[memoria-declarativa]]).
