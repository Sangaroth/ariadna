# Consolidación de sistemas

## Definición

La **consolidación de sistemas** es el proceso por el cual el [[sistema-del-lobulo-temporal-medial]] dirige la estabilización gradual de la [[memoria-declarativa]] en el neocórtex [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7). El neocórtex se considera el depósito permanente de la memoria, mientras el sistema temporal medial es necesario durante el aprendizaje y durante un periodo prolongado posterior [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).

## Mecanismo propuesto

Se propone que las estructuras temporales mediales dirigen la consolidación ligando gradualmente las múltiples regiones corticales separadas que almacenan, cada una, un fragmento de un evento completo [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7). Tras estos cambios graduales, el almacenamiento y la recuperación de la memoria declarativa se vuelven independientes del sistema temporal medial [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).

## Correlato clínico

Esta dinámica temporal explica la [[amnesia-retrograda-temporalmente-graduada]]: como la dependencia del sistema temporal medial decae con el tiempo, su daño afecta más a los recuerdos recientes —aún no consolidados— que a los antiguos, y la extensión del gradiente correlaciona con la extensión del daño hipocampal [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).
