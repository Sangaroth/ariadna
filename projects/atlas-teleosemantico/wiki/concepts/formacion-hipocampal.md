# Formación hipocampal

## Definición

La **formación hipocampal** es el núcleo del [[sistema-del-lobulo-temporal-medial]] e integra el hipocampo propiamente dicho, el giro dentado, el complejo subicular y la corteza entorrinal [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4). El daño bilateral limitado a esta estructura basta para producir una amnesia anterógrada severa y una amnesia retrógrada temporalmente graduada que puede abarcar hasta 25 años [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1).

## Evidencia experimental en monos

Las lesiones por radiofrecuencia limitadas a la región hipocampal (lesión H) produjeron un deterioro persistente 6–9 meses tras la cirugía en la tarea de no-emparejamiento demorado con muestra (normal 79%, H 68%), comparable al causado por lesiones isquémicas con pérdida celular bilateral en CA1 y CA2 (normal 79%, ISC 61%) [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5). El daño isquémico encubierto (*covert*) no parece ser una preocupación seria según los datos disponibles en ratas y monos [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5).

## Confirmación en casos humanos

Los casos humanos confirman que el daño bilateral limitado a CA1 basta para producir un deterioro anterógrado moderadamente severo (pacientes RB y GD), y que el daño que se extiende más allá de CA1 pero permanece dentro de la formación hipocampal produce un deterioro anterógrado más severo [Structure and function of declarative and nondeclarative memory systems, p.6](https://doi.org/10.1073/pnas.93.24.13515#page=6). El daño limitado a la formación hipocampal puede además producir una [[amnesia-retrograda-temporalmente-graduada]] extensa que cubre más de 15 años [Structure and function of declarative and nondeclarative memory systems, p.6](https://doi.org/10.1073/pnas.93.24.13515#page=6).
