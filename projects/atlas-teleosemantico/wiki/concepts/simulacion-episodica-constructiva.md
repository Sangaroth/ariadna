# Simulación episódica constructiva

## Definición

La hipótesis de la simulación episódica constructiva, formulada por Schacter y Addis, sostiene que los sistemas de memoria se activan tanto al imaginar y planificar el futuro como al recuperar el pasado, recombinando elementos de experiencias previas para construir escenarios prospectivos [Update on Memory Systems and Processes, p.10](https://doi.org/10.1038/npp.2010.169#page=10). El fenómeno se emparenta con el «viaje mental en el tiempo» de [[endel-tulving]] [Update on Memory Systems and Processes, p.10](https://doi.org/10.1038/npp.2010.169#page=10).

## Evidencia neural

Johnson y Redish (2007) observaron que, en un punto de decisión, las neuronas de campo de lugar del hipocampo disparan como si la rata «simulara» un camino antes de tomarlo —un correlato neural de la proyección prospectiva [Update on Memory Systems and Processes, p.10](https://doi.org/10.1038/npp.2010.169#page=10). Este hallazgo motiva pensar el cerebro como organizado en sistemas que representan tipos de «conocimiento», no en sistemas separados de percepción y almacenamiento [Update on Memory Systems and Processes, p.10](https://doi.org/10.1038/npp.2010.169#page=10), enlazando con la [[vista-representacional-de-la-memoria]].

## Relevancia teleosemántica

Que el mismo aparato neural sirva tanto para recuperar el pasado como para simular el futuro subraya que la función biológica de la memoria no es archivística sino prospectiva: representar para actuar. Esta orientación a la acción futura es coherente con una lectura teleosemántica del contenido mnémico.
