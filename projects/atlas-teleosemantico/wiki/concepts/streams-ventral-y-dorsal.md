# Streams visuales ventral y dorsal

## Definición

Distinción entre dos grandes vías de procesamiento visual: el **stream ventral**, que sustenta el reconocimiento e identificación de objetos, y el **stream dorsal**, que transforma la información visual para la conducta motora guiada [Contributions of memory circuits to language: the declarative/procedural model, p.6](https://doi.org/10.1016/j.cognition.2003.10.008#page=6).

## Función en el modelo DP

Ullman mapea esta dicotomía sobre los dos sistemas de memoria: el sistema declarativo se relaciona con el stream ventral (reconocimiento de objetos) [Contributions of memory circuits to language: the declarative/procedural model, p.6](https://doi.org/10.1016/j.cognition.2003.10.008#page=6), mientras que el sistema procedimental se relaciona con el stream dorsal, que guía la acción [Contributions of memory circuits to language: the declarative/procedural model, p.12](https://doi.org/10.1016/j.cognition.2003.10.008#page=12). La correspondencia refuerza la idea central del modelo —que los sustratos del lenguaje son los mismos que organizan percepción y acción— y conecta la [[memoria-declarativa]] con el «qué» y la [[memoria-no-declarativa]] con el «cómo». La caracterización del stream dorsal debe mucho a los trabajos de [[leslie-ungerleider]].
