# Componente P600

## Definición

Componente de potencial evocado de polaridad positiva y latencia tardía (~600 ms) asociado al procesamiento de anomalías y reanálisis sintáctico. En la disociación electrofisiológica del lenguaje que recoge el modelo DP, las anomalías sintácticas y morfológicas elicitan negatividades anteriores izquierdas y positividades tardías frente a las dificultades léxico-semánticas, que elicitan el [[componente-n400]] [Contributions of memory circuits to language: the declarative/procedural model, p.20](https://doi.org/10.1016/j.cognition.2003.10.008#page=20).

## Función en el modelo DP

Junto con la [[negatividad-anterior-izquierda-lan]], las respuestas a violaciones gramaticales se postulan como reflejo de procesos de [[memoria-no-declarativa]] procedimental, mientras que el N400 reflejaría procesos de [[memoria-declarativa]] [Contributions of memory circuits to language: the declarative/procedural model, p.20](https://doi.org/10.1016/j.cognition.2003.10.008#page=20). Que las LAN se eliciten también ante secuenciación no lingüística y ante el uso incorrecto de herramientas observado refuerza la tesis de un sustrato procedimental compartido para la estructura jerárquica dentro y fuera del lenguaje [Contributions of memory circuits to language: the declarative/procedural model, p.20](https://doi.org/10.1016/j.cognition.2003.10.008#page=20).
