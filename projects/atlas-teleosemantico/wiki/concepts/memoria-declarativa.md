# Memoria declarativa

## Definición

La **memoria declarativa** es el sistema que sostiene el recuerdo consciente de hechos y eventos, y constituye una de las dos grandes divisiones en que se organiza la memoria, que no es una entidad única sino un conjunto de sistemas con bases cerebrales distintas [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1). Su distinción frente a la [[memoria-no-declarativa]] es la línea divisoria central de la taxonomía: mientras la segunda agrupa capacidades de aprendizaje no conscientes expresadas mediante el desempeño, la declarativa implica acceso consciente al contenido recordado [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1).

## Flexibilidad y accesibilidad

Un rasgo operativo que define a este sistema es su flexibilidad. El conocimiento declarativo es accesible a múltiples sistemas de respuesta, mientras que la memoria no declarativa está más encapsulada y con menos acceso a sistemas no implicados en el aprendizaje inicial [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). Esta diferencia se hace visible en los pacientes amnésicos: aunque pueden aprender una clasificación probabilística al mismo nivel que los sujetos normales, rinden peor en los tests de transferencia sobre fuerzas asociativas, fallando justo en las preguntas más indirectas que requieren un uso flexible del conocimiento [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2).

## Base neural y dependencia temporal

La memoria declarativa depende del [[sistema-del-lobulo-temporal-medial]] y del diencéfalo medial: el daño bilateral en estas regiones afecta severamente los tests declarativos mientras preserva el aprendizaje de habilidades, hábitos y priming [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1). Esta dependencia no es permanente: el neocórtex es el depósito último de la memoria declarativa, y el sistema temporal medial dirige una [[consolidacion-de-sistemas]] gradual tras la cual el almacenamiento y la recuperación se vuelven independientes de él [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).

## Relevancia para el atlas

En clave teleosemántica, la memoria declarativa ejemplifica un sistema individuado por su *función* —dar acceso flexible y consciente a representaciones de hechos y eventos— y no meramente por su sustrato, lo que la conecta con el pilar de individuación funcional desarrollado en [[individuacion-funcional-de-los-sistemas-de-memoria]].
