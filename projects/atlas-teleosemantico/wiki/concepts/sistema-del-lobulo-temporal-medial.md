# Sistema del lóbulo temporal medial

## Definición

El **sistema del lóbulo temporal medial** es el conjunto de estructuras cuya integridad es esencial para la [[memoria-declarativa]], delimitado a partir del modelo en monos [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4). Comprende la [[formacion-hipocampal]] —hipocampo propiamente dicho, giro dentado, complejo subicular y corteza entorrinal— más las cortezas perirrinal y parahipocampal adyacentes [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4).

## Organización del flujo cortical

La corteza entorrinal es la mayor fuente de proyecciones corticales a la región hipocampal y recibe casi dos tercios de su entrada cortical de las cortezas perirrinal y parahipocampal, que actúan así como una vía de convergencia hacia el hipocampo [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4). La gravedad del deterioro de memoria escala al añadir componentes al daño: de las lesiones limitadas a la formación hipocampal (H) a H⁺ (con entorrinal y parahipocampal) y a H⁺⁺ (con perirrinal) [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5).

## Límites del sistema

La amígdala no forma parte del sistema: las lesiones limitadas al complejo amigdalino no afectaron la memoria (77% frente a 80% en controles) [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5). En cambio, las lesiones perirrinal-parahipocampal, sin dañar la formación hipocampal, afectaron la memoria casi tan severamente como lesiones temporales mediales mayores (60% frente a 77%) [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5). Para el aprendizaje de clasificación, en cambio, se postulan sistemas corticoestriatales o cambios graduales intrínsecos al neocórtex, independientes del hipocampo [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4).

## Función consolidadora

Más allá del aprendizaje inicial, el sistema dirige la [[consolidacion-de-sistemas]] gradual de la memoria declarativa en el neocórtex, hasta que el almacenamiento y la recuperación se hacen independientes de él [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).
