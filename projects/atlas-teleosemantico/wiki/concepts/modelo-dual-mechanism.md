# Modelos dual-mechanism de la flexión

## Definición

Familia de modelos lingüístico-psicológicos que postulan **dos mecanismos** distintos para la morfología flexiva: la recuperación de formas irregulares almacenadas y la aplicación de una regla por defecto para las formas regulares. El modelo DP se declara explícitamente compatible con estos modelos «dual-mechanism» [Contributions of memory circuits to language: the declarative/procedural model, p.18](https://doi.org/10.1016/j.cognition.2003.10.008#page=18).

## Relación con el modelo DP

Donde los modelos dual-mechanism lingüísticos especifican la **representación y el cómputo**, el modelo DP aporta la especificación de los **sustratos cerebrales** y sus funciones [Contributions of memory circuits to language: the declarative/procedural model, p.18](https://doi.org/10.1016/j.cognition.2003.10.008#page=18). Son, pues, niveles de descripción complementarios sobre la misma [[morfologia-regular-vs-irregular]]. Esta alianza opone al modelo DP a los [[modelos-conexionistas-de-sistema-unico]], que niegan la existencia de dos mecanismos, y lo conecta con modelos de secuenciación como el de Dominey [Contributions of memory circuits to language: the declarative/procedural model, p.18](https://doi.org/10.1016/j.cognition.2003.10.008#page=18).
