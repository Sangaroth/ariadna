# How the motor system integrates with working memory

## Descripción

Revisión que argumenta que la [[memoria-de-trabajo]] se apoya en el sistema motor mediante [[regiones-motoras-secundarias]] situadas en un [[gradiente-motor-cognitivo|gradiente motor-cognitivo]] del lóbulo frontal, el cerebelo y los ganglios basales [How the motor system integrates with working memory, p.1](https://doi.org/10.1016/j.neubiorev.2019.04.017#page=1). El trabajo sintetiza estudios de neuroimagen que, sobre el [[paradigma-de-sternberg]], muestran activación de pre-SMA, SMA, premotor y cerebelo lateral durante el mantenimiento, con ausencia de actividad motora primaria [How the motor system integrates with working memory, p.6](https://doi.org/10.1016/j.neubiorev.2019.04.017#page=6).

## Aportación

El mecanismo propuesto es la generación de [[trazas-motoras-internas]] que refuerzan la representación mantenida en mente, una estrategia de ensayo redundante respaldada causalmente por estudios de TMS [How the motor system integrates with working memory, p.8](https://doi.org/10.1016/j.neubiorev.2019.04.017#page=8). El paper enmarca el fenómeno en una hipótesis sobre el [[origen-evolutivo-del-vinculo-motor-cognitivo|origen evolutivo del vínculo motor-cognitivo]], proponiendo que las redes cognitivas se desarrollaron a partir de la arquitectura sensorio-motora preexistente [How the motor system integrates with working memory, p.10](https://doi.org/10.1016/j.neubiorev.2019.04.017#page=10).
