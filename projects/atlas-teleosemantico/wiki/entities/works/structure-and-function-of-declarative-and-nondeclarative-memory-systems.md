# Structure and function of declarative and nondeclarative memory systems

## Descripción

Artículo de [[larry-squire]] y [[stuart-zola]] (PNAS, 1996) que sintetiza la evidencia neuropsicológica y experimental a favor de una organización múltiple de la memoria, articulada en torno al contraste entre [[memoria-declarativa]] y [[memoria-no-declarativa]] [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1).

## Tesis y estructura argumental

El trabajo defiende que la memoria no es una entidad única, sino varios sistemas separables por anatomía, características operativas, tipo de información y propósito [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). Repasa varias formas no declarativas —[[aprendizaje-de-clasificacion-probabilistica]] dependiente del [[nucleo-caudado-y-aprendizaje-de-habitos]], [[aprendizaje-de-habilidad-perceptuomotora]], [[aprendizaje-de-gramatica-artificial]] y [[aprendizaje-de-categorias-y-prototipos]]— mostrando en cada una una disociación con el recuerdo consciente [Structure and function of declarative and nondeclarative memory systems, p.3](https://doi.org/10.1073/pnas.93.24.13515#page=3).

## Aportación al modelo del lóbulo temporal medial

A partir del modelo en monos, el artículo delimita el [[sistema-del-lobulo-temporal-medial]] esencial para la memoria declarativa, jerarquiza la contribución de sus componentes —con la [[corteza-perirrinal]] como el más crítico y la amígdala excluida— y, confirmándolo con casos humanos, propone que ese sistema dirige la [[consolidacion-de-sistemas]] gradual en el neocórtex, dejando como huella la [[amnesia-retrograda-temporalmente-graduada]] [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5).
