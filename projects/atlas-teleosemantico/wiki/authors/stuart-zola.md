# Stuart M. Zola

## Perfil

Stuart M. Zola (Zola-Morgan) es coautor, con [[larry-squire]], de "Structure and function of declarative and nondeclarative memory systems" [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1). Su trabajo experimental con el modelo del lóbulo temporal medial en monos fue decisivo para delimitar las estructuras esenciales de la memoria.

## Contribuciones

La serie de lesiones selectivas en monos —limitadas a la región hipocampal, a la corteza entorrinal, al complejo amigdalino o a las cortezas perirrinal y parahipocampal— permitió definir los componentes del [[sistema-del-lobulo-temporal-medial]] y mostrar que el deterioro de memoria escala con el número de componentes dañados, a la vez que la amígdala no forma parte del sistema [Structure and function of declarative and nondeclarative memory systems, p.5](https://doi.org/10.1073/pnas.93.24.13515#page=5). Estos estudios identificaron además a la [[corteza-perirrinal]] como el componente único cuya lesión produce el deterioro más severo [Structure and function of declarative and nondeclarative memory systems, p.6](https://doi.org/10.1073/pnas.93.24.13515#page=6).
