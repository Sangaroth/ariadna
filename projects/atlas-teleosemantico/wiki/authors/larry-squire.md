# Larry R. Squire

## Perfil

Larry R. Squire es uno de los dos autores, junto con [[stuart-zola]], de "Structure and function of declarative and nondeclarative memory systems" y una figura central en la fundamentación de la distinción entre [[memoria-declarativa]] y [[memoria-no-declarativa]] [Structure and function of declarative and nondeclarative memory systems, p.1](https://doi.org/10.1073/pnas.93.24.13515#page=1).

## Contribuciones

Su programa articula la idea de que la memoria es un conjunto de sistemas con bases cerebrales distintas, separables por anatomía, características operativas, tipo de información y propósito [Structure and function of declarative and nondeclarative memory systems, p.2](https://doi.org/10.1073/pnas.93.24.13515#page=2). A partir del modelo del lóbulo temporal medial en monos delimitó el [[sistema-del-lobulo-temporal-medial]] esencial para la memoria declarativa y, en paralelo con casos humanos, mostró que el daño limitado a la [[formacion-hipocampal]] produce amnesia anterógrada severa y una [[amnesia-retrograda-temporalmente-graduada]] [Structure and function of declarative and nondeclarative memory systems, p.4](https://doi.org/10.1073/pnas.93.24.13515#page=4). También sostuvo el papel del lóbulo temporal medial en la [[consolidacion-de-sistemas]] gradual de la memoria en el neocórtex [Structure and function of declarative and nondeclarative memory systems, p.7](https://doi.org/10.1073/pnas.93.24.13515#page=7).
